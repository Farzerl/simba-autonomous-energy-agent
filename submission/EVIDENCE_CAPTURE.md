# Evidence capture checklist

Capture these after the final clean build:

1. Agent overview with the goal, safety boundary and six-step explanation visible.
2. `TARGET_MET` result with forecast, limit, observed demand and headroom.
3. Event timeline showing the complication, replan and verification.
4. Approval mission showing approve/modify/reject/approve-with-limits semantics.
5. ChiShona and isiNdebele selector states.
6. Ubuntu terminal showing both smoke scenarios passing.
7. Official profiler summary showing model, RSS, throughput and thermal fields.

Do not capture personal email, private facility names, raw meter data, API keys,
browser bookmarks or unrelated desktop content. Store approved images in
`evidence/screenshots/` and use clear filenames such as
`01-agent-overview.png` and `02-target-met.png`.
